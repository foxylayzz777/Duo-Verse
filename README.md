# DuoVerse

> **Play Together. Vibe Forever.**

DuoVerse is a social hangout concept for couples, friends, and besties.
It brings shared activities into one place so people can spend time
together online.

## ✨ About

DuoVerse is designed around three core experiences:

-   🎮 **Play together** --- enjoy multiplayer games with friends.
-   💬 **Chat while playing** --- talk and react together during shared
    gaming sessions.
-   🎵 **Listen together** --- enjoy music as part of the hangout
    experience.

The brand direction is cute, clean, premium, and light, with a soft
pastel visual identity.

## 🌐 Project

-   **Website:** https://lovebirds-arcade.vercel.app
-   **Hosting / deployment:** Vercel

## 🚀 Getting Started

To run the project locally, clone the repository:

``` bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>
```

Install dependencies using the package manager configured by the
project. For a Node.js project, this is commonly:

``` bash
npm install
```

Create a local environment file if the project requires environment
variables:

``` bash
cp .env.example .env
```

Add your own development credentials and configuration to `.env`.
**Never commit secrets, database passwords, API keys, or production
environment variables to GitHub.**

Start the development server using the script defined in `package.json`,
commonly:

``` bash
npm run dev
```

The exact commands may differ depending on the repository's framework
and scripts.

## ⚙️ Configuration

If the app connects to Neon, configure its database connection string
